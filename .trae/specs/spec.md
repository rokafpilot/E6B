# ASA CX-3 Style Electronic E6B Flight Computer - Product Requirements Document

## Overview
- **Summary**: ASA CX-3 전자식 E6B 비행 계산기와 동일한 기능을 제공하는 웹/모바일 앱
- **Purpose**: 조종사가 비행 계획 및 운항 중 사용할 수 있는 정확하고 사용하기 쉬운 비행 계산 도구 제공
- **Target Users**: 학생 조종사, 민간 조종사, 항공 정비사, 항공 관제사 등 FAA/캐나다 항공 시험 응시자 및 실제 운항 조종사

## Goals
- ASA CX-3의 핵심 계산 기능 100% 동일한 정확도로 구현
- 직관적인 메뉴 구조와 사용자 인터페이스 제공
- 단위 변환, 타이머, 계산기 등 부가 기능 통합
- 다양한 테마(표준/야간/주간) 지원
- 즐겨찾기 기능으로 자주 사용하는 기능 빠른 접근

## Non-Goals
- 실제 하드웨어 기기의 물리적 디자인 구현 (기능적 동일성만 목표)
- GPS 연동, 실시간 기상 데이터 연동 등 외부 서비스 연동 기능
- FAA 시험 인증 획득 (기능적 정확성만 목표)
- 인쇄 기능이나 보고서 생성 기능

## Background & Context
- ASA CX-3는 FAA 및 캐나다 항공 지식 시험에서 사용이 승인된 전자식 E6B 비행 계산기
- 비행 계획의 자연스러운 흐름에 맞춰 메뉴가 구성되어 있으며, FLT, PLAN, TIMER, CALC, W/B 5가지 주 메뉴로 구성
- 12가지 단위 변환 카테고리, 38가지 단위 지원, 100개 이상의 계산 기능 탑재

## Functional Requirements

### 주 메뉴 시스템
- **FR-1**: 5가지 주 메뉴(FLT, PLAN, TIMER, CALC, W/B)를 제공해야 함
- **FR-2**: 즐겨찾기(Favorites) 기능을 제공하여 자주 사용하는 기능을 빠르게 접근할 수 있어야 함
- **FR-3**: 환경 설정(SET) 메뉴에서 테마, 단위 기본값, 시간대 설정을 변경할 수 있어야 함

### FLT (E6-B 함수)
- **FR-4**: 단위 변환: 거리, 속도, 시간, 온도, 압력, 부피, 비율, 무게, 상승/하강률, 상승/하강각, 토크, 각도 (총 12카테고리, 38단위)
- **FR-5**: 고도 계산: 운고(Cloud Base), 압력 고도(Pressure Altitude), 밀도 고도(Density Altitude)
- **FR-6**: 표준 대기(Standard Atmosphere) 계산
- **FR-7**: 대기 속도 계산: 계획 TAS, 실제 TAS, 요구 CAS, 계획 Mach 번호, 실제 Mach 번호
- **FR-8**: 연료 계산: 연료 소비량, 연료 소비율, 지상 속도, 체공 시간
- **FR-9**: 활공(Glide) 계산
- **FR-10**: 상승/하강(Climb & Descent) 계산
- **FR-11**: 바람 성분 계산: 정면풍/측풍 성분
- **FR-12**: 예상 도착 시간(ETA) 계산
- **FR-13**: To-From 계산
- **FR-14**: 자기 방위 결정(Determine Compass Heading)
- **FR-15**: 바람 보정(Wind Correction)
- **FR-16**: 등각 항로선(Loxodromic Line) 계산
- **FR-17**: 홀딩 패턴(Holding Pattern) 계산: 진입 방법, 홀딩 상세 정보

### PLAN (비행 계획 함수)
- **FR-18**: 비행 계획 세그먼트별 계산 기능
- **FR-19**: 총 비행 시간, 총 연료 소비량 집계

### TIMER
- **FR-20**: 스톱워치(Stopwatch): 위로 세기
- **FR-21**: 카운트다운 타이머(Countdown Timer): 아래로 세기

### CALC (계산기)
- **FR-22**: 기본 사칙연산(+, -, ×, ÷) 지원
- **FR-23**: 제곱근(√) 함수 지원
- **FR-24**: 부호 변경(+/-) 기능 지원

### W/B (무게 및 균형)
- **FR-25**: 무게 및 균형(Weight & Balance) 계산
- **FR-26**: 무게 이동 공식(Weight Shift Formula) 계산
- **FR-27**: %MAC (평균 공력 시위 백분율) 계산

## Non-Functional Requirements
- **NFR-1**: 계산 정확도: ASA CX-3 매뉴얼의 예제 값과 비교 시 ±0.1% 이내 오차
- **NFR-2**: 응답 속도: 모든 계산은 100ms 이내에 결과를 반환해야 함
- **NFR-3**: UI 가독성: 모든 화면은 최소 14pt 이상의 글꼴 크기로, 입력값과 계산 결과값을 명확히 구분하여 표시
- **NFR-4**: 단위 일관성: 입력값의 단위를 명확히 표시하고, 필요 시 단위 전환(CONV) 기능 제공
- **NFR-5**: 오프라인 지원: 인터넷 연결 없이 모든 기능이 동작해야 함
- **NFR-6**: 크로스 플랫폼: 웹 브라우저(데스크톱/모바일)에서 동일하게 동작해야 함

## Constraints
- **Technical**: 프론트엔드 전용 앱으로 구현 (서버리스)
- **Business**: ASA CX-3와 기능적 동일성 유지 (UI/UX는 현대적 웹 표준에 맞춰 개선 가능)
- **Dependencies**: 외부 라이브러리 의존성 최소화, 계산 로직은 직접 구현

## Assumptions
- 사용자는 기본적인 항공 용어와 E6B 계산 개념에 익숙하다고 가정
- 미 입력 필드는 기본값 또는 0으로 처리 (단, 필수 입력은 검증 후 오류 메시지 표시)
- 기본 단위는 국제 표준 단위계(미터법)를 기본으로 하되, 영국 단위계 지원

## Acceptance Criteria

### AC-1: 밀도 고도 계산 정확도
- **Type**: `rule`
- **Given**: 사용자가 압력 고도 5000ft, OAT 25°C를 입력함
- **When**: 밀도 고도 계산을 실행하면
- **Then**: 계산 결과가 약 7900ft (ASA CX-3 표준값 기준)로 나와야 함
- **Pass Condition**: 계산 결과와 ASA CX-3 표준값의 차이가 50ft 이내
- **Evidence**: 유닛 테스트 케이스 통과 결과

### AC-2: 바람 보정 계산 정확도
- **Type**: `rule`
- **Given**: TAS 120kt, 진로(TC) 090°, 풍향 270°, 풍속 20kt를 입력함
- **When**: 바람 보정 계산을 실행하면
- **Then**: 진방위(TH) 090°, 지상 속도(GS) 140kt로 계산되어야 함
- **Pass Condition**: 각도는 ±1°, 속도는 ±1kt 이내 오차
- **Evidence**: 유닛 테스트 케이스 통과 결과

### AC-3: 단위 변환 정확도
- **Type**: `rule`
- **Given**: 사용자가 1 노트(kt)를 km/h로 변환 요청함
- **When**: 단위 변환 기능을 실행하면
- **Then**: 1.852 km/h 로 변환되어야 함
- **Pass Condition**: 변환값과 표준값의 차이가 0.001 이내
- **Evidence**: 유닛 테스트 케이스 통과 결과

### AC-4: 무게 및 균형 계산 정확도
- **Type**: `rule`
- **Given**: 총 중량 2500lb, 총 모멘텀 100,000 in-lb, MAC 앞전 100in, MAC 시위 80in를 입력함
- **When**: %MAC 계산을 실행하면
- **Then**: %MAC = ((100000/2500) - 100) / 80 × 100 = 50% 로 계산되어야 함
- **Pass Condition**: 계산 결과와 예상값의 차이가 0.5% 이내
- **Evidence**: 유닛 테스트 케이스 통과 결과

### AC-5: 메뉴 탐색 유용성
- **Type**: `rubric`
- **Dimension**: 메뉴 구조의 직관성 및 탐색 효율성
- **Scale**: 1-5
- **Anchors**: 1 = 메뉴 구조가 혼란스러워 원하는 기능을 찾기 어려움; 3 = 기본 기능은 쉽게 찾을 수 있으나 일부 고급 기능은 탐색이 어려움; 5 = FLT→PLAN→TIMER→CALC→W/B의 자연스러운 흐름으로 모든 기능을 3번 이내의 클릭으로 접근 가능
- **Pass Threshold**: >= 4
- **Evidence**: 사용자 시나리오 기반 UI 테스트 결과

### AC-6: 테마 지원 및 가독성
- **Type**: `rubric`
- **Dimension**: 화면 테마 가독성 및 사용자 경험
- **Scale**: 1-5
- **Anchors**: 1 = 야간/주간 테마가 없거나 가독성이 매우 떨어짐; 3 = 기본 테마만 지원하거나 일부 화면에서 가독성 문제가 있음; 5 = 표준/야간/주간 3가지 테마를 지원하며, 모든 테마에서 입력값과 결과값의 구분이 명확하고 고대비로 가독성이 우수함
- **Pass Threshold**: >= 4
- **Evidence**: 시각적 검토 및 각 테마별 스크린샷

### AC-7: 계산 속도 및 응답성
- **Type**: `rule`
- **Given**: 사용자가 어떤 계산 기능을 사용하든
- **When**: 입력 후 계산 버튼을 누르면
- **Then**: 100ms 이내에 결과가 표시되어야 함
- **Pass Condition**: 모든 계산 기능의 95% 이상이 100ms 이내 응답
- **Evidence**: 성능 측정 프로파일링 결과

### AC-8: 타이머 기능 정확도
- **Type**: `rule`
- **Given**: 카운트다운 타이머를 1분(60초)으로 설정함
- **When**: 타이머를 시작하고 실제 60초가 경과하면
- **Then**: 타이머가 0초가 되고 알림이 발생해야 함
- **Pass Condition**: 실제 시간과의 오차가 1초 이내
- **Evidence**: 타이머 동작 테스트 영상 또는 로그
